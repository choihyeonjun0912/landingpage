FAQ

자주 묻는 질문

더 궁금한 점은 문의 양식으로 남겨주세요. MEP 코디네이션 담당 엔지니어가 답변합니다.

False Resolved란 무엇입니까?

간섭이 실제로 해소되지 않았는데도 검출 도구에서 ‘해결됨’으로 처리되는 현상입니다. 객체가 삭제되거나, GlobalId가 재발급되거나, 분류가 바뀌어 Search Set에서 빠지면 간섭이 더 이상 검출되지 않아 해결로 표시됩니다. SYNCRA는 개정 전후 객체를 짝지어 이런 경우를 가려냅니다.

Navisworks를 대체해야 합니까?

아닙니다. SYNCRA는 보완재입니다. 기존 Navisworks 간섭 보고서와 IFC 개정본을 입력으로 받아, 검출 이후의 해소 판정과 영향 추적을 더합니다.

어떤 파일이 필요합니까?

Navisworks 간섭 보고서(XML 또는 HTML 내보내기)와 개정 전후 IFC 모델 두 개가 필요합니다. 연합 모델 기준으로 기계·전기·구조 공종을 함께 분석합니다.

보안이 엄격한 FAB 현장에서도 쓸 수 있습니까?

FAB 보안 요건에 맞춘 온프레미스 버전을 개발 중이며 2027년 하반기 출시를 목표로 합니다. 그 전까지는 온프레미스 진단 방식을 협의합니다.

생성된 수정안이 모델에 자동 반영됩니까?

엔지니어가 승인한 대안만 IFC 패치로 적용합니다. 대안 생성은 학습 모델이 맡지만, 통과 판정은 결정론적 규칙이, 최종 채택은 엔지니어가 합니다.

요금은 어떻게 책정됩니까?

현장 단위 월 구독입니다. 검증 플랜은 현장당 월 49만 원, 재설계 플랜은 월 149만 원이며, 전사 도입은 3개월 유료 파일럿으로 시작합니다.

설계변경, 이제 증명하세요

최근 개정본 하나면 충분합니다. 간섭 보고서와 IFC 전후 모델을 보내주시면 ‘해결됨’ 목록의 거짓 해소를 가려 리포트로 돌려드립니다.
